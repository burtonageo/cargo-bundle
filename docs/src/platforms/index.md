# Platforms

Each page covers the formats for one operating system and the settings that
only apply there. Signing is covered separately in [Signing](../signing.md).

- [macOS](macos.md): `osx`, `dmg`
- [iOS](ios.md): `ios`, `ipa`
- [Android](android.md): `apk`
- [Linux](linux.md): `deb`, `appimage`
- [Windows](windows.md): `msi`, `wxsmsi`, `exe`
